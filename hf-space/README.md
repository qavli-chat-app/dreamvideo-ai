# DreamVideo AI free demo backend

This is an experimental backend template using the open-source `damo-vilab/text-to-video-ms-1.7b` model. It is not a promise of unlimited or always-available generation: free GPU quota, queueing, model compatibility, and memory constraints apply.

For a real deployment, create a Hugging Face Space using ZeroGPU-compatible hardware if available, then upload the contents of this folder. Confirm the Space's current hardware and model licensing/usage terms before publishing. Never add paid hardware or billing if you want to keep the project free-only.
